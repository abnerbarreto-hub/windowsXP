# Instalação do Windows XP no VirtualBox

## 1. Criando a Máquina Virtual

![Criando VM](images/criando-vm.png)

1. Abra o VirtualBox.
2. Clique em **Novo**.
3. Escolha **Windows XP (32-bit)**.

---

## 2. Configurando a Memória RAM

![Memória RAM](images/memoria-ram.png)

- Recomenda-se entre **512 MB e 1024 MB**.

---

## 3. Criando o Disco Virtual

![Disco Virtual](images/disco-virtual.png)

1. Clique em **Criar um disco rígido virtual agora**.
2. Escolha **VDI**.
3. Defina pelo menos **10 GB**.

---

## 4. Adicionando a ISO

![Selecionando ISO](images/selecionando-iso.png)

1. Vá em **Configurações > Armazenamento**.
2. Selecione a ISO do Windows XP.

---

## 5. Iniciando a Instalação

![Instalador XP](images/instalador-xp.png)

1. Inicie a máquina virtual.
2. Pressione qualquer tecla para iniciar pelo CD.

---

## 6. Formatando a Partição

![Formatação NTFS](images/formatacao-ntfs.png)

- Escolha **Formatar usando NTFS**.

---

## 7. Configuração Final

![Área de Trabalho XP](images/windows-xp-pronto.png)

Após a instalação, configure:
- Nome do computador
- Data e hora
- Rede

---

# Resultado Final

![Windows XP](images/windows-xp-final.png)

Instalação concluída com sucesso!
